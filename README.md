PySentinel – System Health Snapshot
## About the Project
PySentinel is a Python-based system monitoring tool that generates a basic system health report for a selected folder.

## Features
Checks total, used, and free disk space.

Calculates folder size.

Finds the top 5 largest files.

Converts bytes into readable units (KB, MB, GB).

Saves the system health report in health_log.txt.

## Technologies Used
Python

OS Module

Shutil Module

Datetime Module

## How to Run
Open the project folder in VS Code.

Open the terminal.

Run: python monitor.py

Enter a folder path when prompted.

Press Enter to use the current folder.

## Project Files
monitor.py – Main Python program.

health_log.txt – Saved health reports.

test_folder/ – Folder used for testing.
